# 本地预览、上传与真机验证

本次上线的原包保存在 `releases/linghun-yuanxiang-1.0.1.zip`。解压后根目录直接包含 index.html、app.js、media.js、style.css 和 assets。

## 本地启动

在本项目目录运行 `node server.mjs`，访问 http://127.0.0.1:4187/ 。答题、图片、动画、声音与书签下载可在普通浏览器体验。点击「去探寻」解锁声音。

修改分拆源码后运行 `node build.mjs`。修改前后可用 `node verify.mjs` 核对与已发布快照的差异。verify 使用发布版固定哈希，因此主动改动之后应为下一版单独生成快照。

## 在 Builder Hub 上传

1. 登录自己的小红书创作服务平台，进入 Builder Hub 的小工具管理。
2. 使用当前上传页提供的改写口令检查包的合规性，特别核对兼容基线和当前包体限制。
3. 填写名称、简介、图标、封面与场景标签。《灵魂原像》使用「娱乐测试」。
4. 在部署前确定版本号，再上传 ZIP。版本号改动后，应按平台提示重新部署。
5. 扫平台生成的预览二维码，在手机验收。
6. 阅读并确认平台发布规范，提交审核，以管理列表中的实际状态为准。
7. 发布后，在笔记的添加组件入口选择该小工具。

[小红书创作服务平台](https://creator.xiaohongshu.com/) · [当前平台能力清单](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)

## 实际验收

- 点击去探寻，BGM 开始，右上角图标旋转，开关统一控制声音。
- 逐题确认选项文字和图像对应，选择后水滴声和自动换题正常。
- 返回上一题，已选项保留，快速操作无错位。
- 最后一题结束，Loading、飞入和翻牌的声音与动画衔接。
- 解读按钮出现后点击，逐字与书写声一起开始，结束后声音停止。
- 书签完整显示，按钮位于下方，允许或拒绝相册权限都有可理解反馈。
- 图鉴的 16 张牌均能打开并读取对应长文。
- 后台切换、静音、恢复、长文滚动及系统顶部按钮避让正常。

## 满屏与保存

页面会读取可用的 `getWindowInfo`，设置安全区域与按钮避让，缺少接口时使用 CSS 回退。全屏开场最终由小红书的承载入口决定，应通过目标客户端预览确认。

保存书签调用 `window.xhs.miniTool.writeTempFile({ data })` 和 `saveImageToPhotosAlbum({ filePath })`。当前书签数据为图片 data URI，临时文件写入失败时再直接传入 data URI。普通浏览器回退为下载。相册授权只在用户点击保存时触发。[平台图片保存说明](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-4)
