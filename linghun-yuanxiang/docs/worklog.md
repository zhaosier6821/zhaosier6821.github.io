# 从视觉测试到上线

记录截至 2026-11-18 的实际交付。材料来自项目源码、部署时的平台反馈及创作者的验收反馈。

## 产品与视觉

最初是《精神形状生成器》，后定名《灵魂原像》，slogan 为「当你的灵魂化作世间一物，那会是什么？」。问卷从早期 12 道缩为最终 8 道，每题 4 个选项，固定匹配 16 张结果牌。评分保留源码中每个选项的权重与校准值。

视觉为深夜梦核、半透明月光晶体、细碎宝石与银色卡牌边框。每种意象有独立场景。答题页用森林、雨与漂浮题干；结果页用天空、湖水倒影与悬浮卡牌。

卡牌局部动画通过主体图层、透明叠加图层、逐帧条带及 CSS 时间参数完成。木马包含支柱与环形马匹动画，鸟用翅膀逐帧条带，镜面有湖水波纹。可在 `src/data.js` 的 motions 与 `src/app.js` 的 mountMotion 中追踪每一张。

## 交互逐步完成

1. 答案点击后自动换题，底部返回上一题，避免重复点下一题。
2. 首页只让 16 种名字漂浮，结果牌留到答题完成揭示。
3. Loading 后卡牌飞入并翻转，点击「解读卡牌」才出现文字。
4. 解读包含名称、诗句和对应长文，羽毛笔逐字写出。
5. 「保存卡牌书签」放在解读下面，点击先预览完整长书签。
6. 预览图下方提供存相册及返回按钮，书签保留原始牌面及末句祝愿。
7. 图鉴能浏览全部 16 种牌，每张可进入对应解读。
8. 处理移动端横向溢出、缩放、顶部按钮避让与选项发光裁切。

## 音乐排障

原生小组件阶段，所有声音无声并出现 A2。采用本地缓存写入、分段追加与校验，再交给原生播放器后，用户明确反馈声音问题解决。后续迁移为 HTML 小工具时，音乐改用包内编码与 Web Audio。两套实现及音源记录集中在 [audio.md](audio.md)。

## 应用入口排查

最初 `widget` 工程通过开发者工具上传。讨论全屏打开时，对照了创作者最早给出的 [shamsham 参考仓库](https://github.com/daafffodil/xiaohongshu-live-photo-guide) 和他人小工具分享入口，确认要交付 Builder Hub 的离线 HTML 小工具。

本次上线 AppID 为 `6afc107a8d28de0015a2032c`。原生小组件 AppID 和 Builder Hub 小工具是各自的应用。读者应使用自己账号的应用与上传入口。

全屏涉及平台容器和启动方式。源码只负责使用可用窗口与避让顶部控件，没有调用网页 Fullscreen API。不要用替换他人的 AppID 或拼接示例链接来代替平台发布。

## 部署与修复

首次 HTML 包在平台显示部署成功，但模拟器里的动态选项图宽度为 0，静态背景能显示。继续实测发现运行时动态资源存在加载兼容问题。为该次发布将动态图片编码进本地 `media.js`，原图片字节保留，重新部署后 32 张选项图全部正常加载。

官方文档允许包内资源和动态路径，并推荐适用的独立静态素材外移。因此这里记录的是此次具体环境中的兼容修复，不能推断所有动态路径都不被支持。后续优化应结合当前平台规则实测。

在上传成功后修改版本号，点击发布曾返回「版本号已变更，请重新上传部署」。以 1.0.1 重新上传同一修复包后提交成功，后台进入「审核中」，随后查到「已发布」。2026-11-18 创作者确认上线成功。

## 验证的边界

归档前的本地程序核对 65,536 种答卷组合，匹配结果与原模型一致。平台模拟器完成 8 题、32 图加载、结果翻牌、解读、书签预览及图鉴选牌。模拟器里从笔记「用一用」打开，页面和承载窗口均为 390 × 844。

项目上线成功、原生阶段声音修好有用户反馈。所有 iOS / Android 版本、系统音频中断及真实相册授权没有做全机型验证。这些范围由复用者在目标手机验收。
